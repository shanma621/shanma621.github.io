Rental Demand Analysis & Automated Genre Reporting

A PostgreSQL reporting workflow designed to analyze movie rental demand by store location and genre using relational joins, transformation functions, summary reporting tables, triggers, and stored procedures.

View GitHub Repository

Project Overview

This project was designed to simulate a lightweight business intelligence reporting pipeline using PostgreSQL. The workflow identifies which movie genres generate the highest rental demand at each store location in order to support inventory planning and operational decision-making.

The project combines relational database design, SQL transformations, aggregation reporting, trigger-based automation, and stored procedures to create a reusable reporting workflow rather than a one-time query.

Business Question

Which movie genres generate the highest rental demand at each store location?

Understanding genre demand by location can help businesses:

  • Optimize inventory allocation
  • Improve purchasing decisions
  • Track changing customer preferences
  • Support operational reporting workflows

Technical Workflow

Data Sources

The analysis combines data from multiple relational database tables:

  • Rental transactions
  • Inventory records
  • Film information
  • Genre/category mappings
  • Store location data

Data Transformation

Custom PL/pgSQL functions were created to transform rental timestamps into separate month and year fields to improve reporting flexibility and support future time-series analysis.

Reporting Tables

The workflow generates:

  • A detailed transaction-level reporting table
  • A summarized genre-by-store reporting table

Automation

Trigger logic was implemented to automatically refresh summary reporting metrics whenever new detail records are inserted into the reporting table.

A stored procedure was also created to rebuild the reporting workflow for recurring monthly reporting.

SQL Concepts Demonstrated

  • Relational database design
  • SQL joins
  • Aggregation and grouping
  • PL/pgSQL functions
  • Database triggers
  • Stored procedures
  • Operational reporting workflows

Example Query


SELECT
    store_id,
    genre,
    COUNT(*) AS rental_count
FROM rental_genre_detail
GROUP BY store_id, genre
ORDER BY store_id, rental_count DESC;
